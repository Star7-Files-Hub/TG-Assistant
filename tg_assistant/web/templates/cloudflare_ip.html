控制何时更新 DNS 记录

开启后，上面「DNS 记录」里的每一条都会展开成三条同域名、同类型的 A 记录， 各自带上运营商标记（写进 Cloudflare 记录的备注），客户端按自己所在的网自动选。 某一家这次没抓到 IP 就**保留原记录不动**，绝不会拿别家的 IP 顶替。

兜底值：某个运营商没单独设就用它。0 = 不限制

按运营商分别设阈值 —— 三网测速差距极大，共用一个阈值会让移动那条永远不更新。
